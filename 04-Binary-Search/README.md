# Binary Search

### Bài tập

1. Tìm một phần tử trong mảng đã sắp xếp.
2. Tìm vị trí xuất hiện đầu tiên của một giá trị.
3. Tìm vị trí xuất hiện cuối cùng.
4. Đếm số lần xuất hiện của một giá trị.
5. Tìm căn bậc hai nguyên bằng binary search.

Mục tiêu: nhận biết khi nào có thể dùng binary search `O(log n)`.
