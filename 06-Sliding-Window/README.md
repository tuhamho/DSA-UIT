# Sliding Window

### Bài tập

1. Tìm tổng lớn nhất của đoạn con liên tiếp độ dài `k`.
2. Tìm độ dài chuỗi con không lặp ký tự.
3. Tìm đoạn con nhỏ nhất có tổng ít nhất `target`.
4. Tìm số lượng phần tử khác nhau trong mỗi cửa sổ độ dài `k`.

Mục tiêu: cập nhật cửa sổ thay vì tính lại toàn bộ đoạn con.
